# 💬 CHAT-APP

A real-time chat application built with **Node.js**, **Express**, **Socket.IO**, and plain **HTML/CSS/JavaScript**.

---

## 🚀 Features

- Real-time communication with Socket.IO
- Frontend built with vanilla HTML/CSS/JS
- Custom message formatting
- Modular backend structure
- User join/leave notification (planned via `utils/users.js`)
